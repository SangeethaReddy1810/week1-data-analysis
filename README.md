# Week 1 Data Analysis Project

## Overview
This project focuses on building a strong foundation in data handling, SQL, and Excel as part of the STEM OPT training program.

## Objectives
- Practice SQL queries (SELECT, JOIN, GROUP BY, subqueries)
- Perform data cleaning using Excel/Pandas
- Analyze sales dataset
- Generate reports and insights

## Dataset
- Contains 100+ records of customer and sales data
- Cleaned by removing duplicates, handling missing values, and standardizing formats

## SQL Work
- Aggregations (SUM, AVG)
- Joins between tables
- Subqueries for advanced filtering
- Customer and product analysis

## Key Insights
- Top products contribute majority of revenue
- Sales trend shows consistent growth
- Majority of customers fall between ages 25–40

## Tools Used
- SQL
- Microsoft Excel
- Python (Pandas)

## Files Included
- `data/cleaned_dataset.xlsx`
- `sql/queries.sql`
- `reports/Week1_Report.pdf`
